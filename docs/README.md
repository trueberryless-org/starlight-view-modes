# `starlight-view-modes-docs`

Documentation for the `starlight-view-modes` Starlight plugin, deployed at [starlight-view-modes.netlify.app](https://starlight-view-modes.netlify.app).

## Documentation

Run the documentation locally by running the following command in your terminal:

```shell
pnpm run dev
```

Content can be found in the [`src/content/docs/`](https://github.com/trueberryless-org/starlight-view-modes/tree/main/docs/src/content/docs) directory.
