## Features

<CardGrid stagger>
  <Card title="Presentation Mode" icon="laptop">
    Turn your documentation into a beautiful, interactive presentation instantly.
    Perfect for teaching, showcasing features, or leading workshops directly from
    your docs.
  </Card>
  <Card title="Zen Mode" icon="sun">
    Read your documentation without distractions by hiding the page elements around
    its content. Focus purely on what you are reading.
  </Card>
  <Card title="Data & Extensibility" icon="setting">
    Build your own custom view modes or adapt existing ones using our simple API.
    Get access to internal view mode data in your components.
  </Card>
  <Card title="Seamless Navigation" icon="open-book">
    URLs automatically adapt, sections are preserved during mode switching, and
    keyboard shortcuts make navigation a breeze.
  </Card>
</CardGrid>
