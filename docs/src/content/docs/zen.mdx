Zen Mode hides the elements around the content of a page, e.g. the header and the sidebar, to read documentation without distractions.

<SpeakerNotes>Switch to Zen Mode to show the difference.</SpeakerNotes>

## Entering Zen Mode

Enter Zen Mode using the Zen Mode icon in the header, the "View Modes" section of the table of contents, or a configured [keyboard shortcut](/configuration/#keyboardshortcut), e.g. `Ctrl+Shift+Z` (`Cmd+Shift+Z` on macOS) on this website.
When the header is hidden and no table of contents is visible, the view mode icons are displayed next to the page title.

The Zen Mode version of a page is available at its URL with `/zen-mode/` added after the locale, e.g. [`/zen-mode/getting-started/`](/zen-mode/getting-started/).
A link to a section, e.g. `/zen-mode/getting-started/#installation`, opens the page at this section, and switching between view modes keeps the section being read.

## Navigating in Zen Mode

Links to other pages of the site stay in Zen Mode, e.g. in the content, the sidebar, the footer, or the search results.
[Excluded](/configuration/#exclude) pages and pages not part of the docs [content collection](https://starlight.astro.build/manual-setup/#configure-content-collections), e.g. pages added by other plugins, are opened in the default view mode.

## Hidden elements

By default, Zen Mode hides the header and the sidebar, and keeps the table of contents and the footer.
Each of these elements can be shown or hidden using the [`displayOptions`](/configuration/#displayoptions) option.

Pages with a hero always display the header to be able to leave Zen Mode, and splash pages are not available in Zen Mode as they have no sidebar or table of contents to hide.
